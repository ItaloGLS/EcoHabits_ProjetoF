🌱 EcoTracker

Aplicativo Android para ajudar usuários a criar e acompanhar hábitos ecológicos.

📱 Sobre o projeto

O EcoTracker permite:

Criar hábitos sustentáveis

Acompanhar o progresso

Organizar metas ambientais

🛠️ Tecnologias usadas

Kotlin

Android Studio

ViewBinding

Room (banco de dados local)

Retrofit (requisições para API)

▶️ Como rodar o projeto

Clone o repositório

Abra no Android Studio

Clique em Run (▶️)
